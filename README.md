# Advanced Artifacts
Collect and merge powerful artifacts to gain increasing bonuses to damage and defense against specific mobs or actions.

## Commands
### aagive <player> <artifact-id> <level>
Description: Gives an artifact to a player \
Example usage: /aagive WIX3Y reduce_poison_damage 5 \
Aliases: artifactsgive, advancedartifactsgive \
Permission: advancedartifacts.give
## aainventory
Description: Opens the artifact inventory gui
Example usage: /aainventory
Aliases: advancedartifactsinventory, advancedartifactsinv, artifactsinventory, artifactsinv, aainv, advancedartifacts, artifacts
Permission: advancedartifacts.inventory.self
## aainventory <player>
Description: Opens the artifact inventory gui for a specific player
Example usage: /aainventory WIX3Y
Aliases: advancedartifactsinventory, advancedartifactsinv, artifactsinventory, artifactsinv, aainv, advancedartifacts, artifacts
Permission: advancedartifacts.inventory.other
## aainventoryother <player>
Description: Opens the artifact inventory gui belonging to another player
Example usage: /aainventoryother WIX3Y
Aliases: advancedartifactsinventoryother, advancedartifactsinvother, artifactsinventoryother, artifactsinvother, aainvother, advancedartifactsother, artifactsother
Permission: advancedartifacts.inventory.adminview
## aatinker
Description: Opens the gui for merging two artifacts of the same type and level into an artifact with a higher level
Example usage: /aatinker
Aliases: advancedartifactstinker, artifactstinker, tinker
Permission: advancedartifacts.tinker.self
## aatinker <player>
Description: Opens the gui for merging two artifacts of the same type and level into an artifact with a higher level for a specific player
Example usage: /aatinker WIX3Y
Aliases: advancedartifactstinker, artifactstinker, tinker
Permission: advancedartifacts.tinker.other
## aareload
Description: Reloads the plugin
Example usage: /aareload
Aliases: advancedartifactsreload
Permission: advancedartifacts.reload
